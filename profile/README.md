# Welcome to Cribl Community

Useful examples, tools, labs, and resources built by and for the Cribl Community.

This GitHub organization is a community-owned space for Cribl users, builders, partners, and community members to share practical work that helps others learn faster, build better, and solve real problems.

## Important Note

The repositories in this organization are community-owned and community-maintained.

They are not official Cribl product repositories, and they are not supported, tested, or maintained by Cribl.

Use these projects as examples, starting points, learning resources, or community contributions. Review and test anything carefully before using it in your own environment.

## What You’ll Find Here

This space may include:

* Example configurations
* Demo projects
* Community tools
* Learning labs
* Scripts and utilities
* Reference architectures
* Starter templates
* Helpful experiments

Some projects may be polished and ready to use. Others may be early ideas, prototypes, or examples meant to help you get started.

## How to Use This Community

Start by browsing the repositories and reading the `README.md` in each project. Each repo should explain what it does, how to use it, and whether it is meant for production, learning, testing, or inspiration.

If you find something useful, try it, improve it, ask questions, or share what you learned.

## Contributing

Community contributions are welcome.

Good contributions include:

* Fixing typos or unclear instructions
* Adding examples
* Improving documentation
* Sharing useful scripts or templates
* Opening issues with clear feedback
* Suggesting new ideas
* Helping answer questions

Before contributing, check the repo’s `CONTRIBUTING.md` file if one exists. If a repo does not have one yet, open an issue or pull request and keep it simple.

## Community Expectations

Be helpful. Be clear. Be kind.

We want this to be a useful space for people at different experience levels. Assume good intent, explain your thinking, and help make the work easier for the next person who finds it.

## Support

These repositories are community resources.

They are not official Cribl support channels, and Cribl Support does not provide support for community-owned repositories unless a specific project says otherwise.

For official product documentation, visit the Cribl docs:

https://docs.cribl.io/

For product support, use your normal Cribl support process.

## Licenses

Each repository should include its own license. Check the license in the specific repo before using, modifying, or sharing anything from it.

## Have an Idea?

Open an issue in the relevant repo, or start a discussion if discussions are enabled.

If the idea does not fit an existing repo, open an issue in this welcome repo and tell us what you want to build or share.
